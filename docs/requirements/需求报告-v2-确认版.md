## 1. 范围：做什么、不做什么

### 1.1 本期交付（范围内）

| 模块 | 范围 |
| --- | --- |
| 项目管理 | 新建 / 编辑 / 删除（确认弹窗）；列表显示编号、名称、记录数；编号唯一性校验 |
| 检测记录（立柱 / 横梁两模板） | 楼层、构件位置、尺寸结果、截面尺寸要求（预置条文下拉）、1~6 个检测面 × 每面 5 个厚度读数、**最小值自动计算**；新增 / 编辑（模板不可切换）/ 删除 / 展开明细 |
| 缺陷检测填报 | 隐患图片（拍照或相册，≤20MB，存原图）、缺陷类型（预置 10 类 + 自定义）、工程部位、隐患等级（高/中/低，默认中）、整改方案、相关规范、补充建议、绑定项目（选填）、报告人自动取本机配置 |
| 报告管理 | 列表（按时间倒序、等级徽标、缩略图）、顶部统计、按等级筛选、详情（含大图）、删除（确认弹窗 + 自动解绑项目） |

| 我的 | 个人信息配置（姓名 / 部门）、数据概览（项目 / 检测记录 / 报告数）、数据管理（导出备份 / 导入恢复 / 清除全部报告 / 持久化授权 / 重建缩略图）、关于（名称 / 版本 / 出品方） |
| 数据与离线 | 数据只存本机（IndexedDB）；整库备份为 zip（含原图）；离线可用；**新增**：Android APK 渠道（导出文件写入手机「下载/幕墙检测/」） |

## 2. 对 v1 的具体修订（逐条）

### 2.1 导航结构（替代 v1 §2.1）

```
主界面（底部 3 个 Tab）
 ├─ 项目      项目管理 + 项目详情（检测记录、导出 Word）
 ├─ 报告      缺陷填报 + 报告管理
 └─ 我的      个人信息配置 / 数据概览 / 数据管理 / 关于
```

变化：取消「登录页」与 4 Tab 结构；原「应用」下的 3 个子 Tab 并入「报告」；「统计」取消。

### 2.2 检测填报（修订 v1 §3.3.2 的"报告人"一行）

| 字段 | 修订后 |
| --- | --- |
| 报告人 / 部门 | ~~取当前登录用户，不可改~~ → **取本机「个人信息配置」（姓名 / 部门），可在「我的」中修改；已保存的报告保持当时的署名** |

其余 7 个字段（隐患图片、缺陷类型、工程部位、隐患等级、整改方案、相关规范、补充建议、绑定项目）与 v1 §3.3.2 一致；预置缺陷类型 10 类与 v1 §3.3.3 一致。

### 2.3 检测记录（补充 v1 §3.5.2 的两点实施细节）

1. **检测面标签可自由输入**：v1 写"A/B/C/D/E/F"，实际现场数据出现 `B`、`H`（立柱）与 `t`（横梁）。
   实施为：上限仍为 6 个面，标签可自由填写，界面给出建议值（立柱 B/H、横梁 t）。
2. **横梁截面尺寸要求预置条文为 3 条**：v1 列了 2 条；实际客户报告里还出现过"两句合并"的写法，
   作为第 3 条收录（只追加、不改动已有两条，历史记录按快照保存）。

### 2.4 附页（修订 v1 §4.4 的标签行数）

v1 列 8 个标签；客户**真实报告**的附页信息表为 **9 行**（多一行「图片文件」）。实施按真实报告，即 9 行。

### 2.5 数据管理（替代 v1 §3.7 c）

| v1 要求 | 修订后 |
| --- | --- |
| 清除全部速记、清除全部报告 | ~~清除速记~~（无速记）；**清除全部报告**保留（确认弹窗、提示不可恢复） |
| — | **新增**：导出备份（整库 zip，含原图）、导入备份（覆盖式，导入前确认）、申请持久化授权、重建全部缩略图 |

### 2.6 新增：Android APK 交付渠道

需求方要求提供 `.apk` 安装包。实施为 Capacitor 壳 + 同一份前端代码，行为差异仅三处（导出落盘、返回键、离线缓存），
详见《本地 APK 打包指南》与《交付验收报告》第 6 节。

## 3. 验收标准（每条都能跑）

| # | 验收项 | 判定方式 |
| --- | --- | --- |
| 1 | 立柱/横梁两类记录可混录，每面 5 值，最小值自动算出 | 界面 + 导出 docx 双查；单元测试覆盖 |
| 2 | 免责/空值口径：截面要求为空 → 报告显示「无」 | docx 文本断言 |
| 3 | 导出 docx 与客户既有报告**逐属性一致** | 三道闸门（复刻基线 / 对齐真实报告 / 无 Python 自检）差异为 0 |
| 4 | 附页：每份独立成页、9 行信息表、标题「检测报告附页（N/总数）」 | 闸门 + 附页测试 |
| 5 | 数据只在本机；备份/恢复完整（含原图，缩略图重建） | 真机 + 自动化（备份→清除→导入） |
| 6 | 离线可用（断网可打开、可记录、可导出） | 真实浏览器 + 安卓实测 |
| 7 | 手机端可用：触控区 ≥44px、键盘不遮挡保存、返回键不回退到退出 | 桌面 E2E + 安卓模拟器 |
| 8 | 交付包可部署（Nginx / IIS / 内置静态服务），`.mjs` MIME 正确 | 用包内 `serve_static.py` 起服务冒烟 |

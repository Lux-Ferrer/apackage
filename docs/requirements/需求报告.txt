建筑幕墙检测管理 APP 需求报告

一、项目概述

1.1 产品定位
面向建筑幕墙检测人员的现场检测记录与报告管理工具。检测人员在现场通过手机完成：缺陷拍照登记、检测结果手动填写、检测数据（立柱/横梁截面尺寸）录入、项目归档，并一键导出符合规范排版的 Word 检测报告。

1.2 目标用户与使用场景
a) 用户：幕墙检测工程师 / 检测员；
b) 场景：检测现场（可能无网络），拍照取证 → 手动填写缺陷结论 → 录入尺寸检测数据 → 回办公室导出 Word 报告。

1.3 核心价值
a) 现场一站式记录：缺陷报告 + 尺寸数据 + 速记；
b) 报告与项目关联：缺陷报告绑定项目后可随项目 Word 报告一并输出；
c) 离线可用，数据不出设备。

二、总体功能架构

2.1 导航结构
登录页
  └─ 主界面（底部导航 4 个主 Tab）
       ├─ 应用（内含 3 个子 Tab）
       │    ├─ 工作台（速记）
       │    ├─ 检测填报（缺陷报告）
       │    └─ 报告管理
       ├─ 项目（项目管理）
       ├─ 统计
       └─ 我的

2.2 功能模块清单
模块：登录
功能：本地用户校验、会话保持、退出

模块：速记
功能：文字 + 图片的快速记录

模块：检测填报
功能：拍照 + 手动填写缺陷结论 + 绑定项目（核心模块）

模块：报告管理
功能：报告列表/筛选/详情/删除

模块：项目管理
功能：项目增删改查、检测记录（立柱/横梁模板）、Word 导出

模块：统计
功能：报告量、等级分布、7 天活动、缺陷类型分布

模块：我的
功能：用户信息、数据清除、退出登录

三、功能需求详述

3.1 登录
字段：姓名 — 必填 — 校验：本地用户名单校验
字段：部门 — 必填 — 校验：文本
字段：部门编码 — 必填 — 校验：4 位大写字母（如 KJGL）

a) 校验通过后进入主界面，登录态本地保持（刷新不丢失）；
b) 提供"查看示例账号"入口展示演示账号；
c) 退出登录仅清除会话，业务数据保留。

3.2 工作台
现场情况快速记录，纯手动。
文字输入：多行文本框；
图片附件：拍照或相册选择，每条速记 1 张（≤20MB，jpg/png 等常见格式）；
保存：列表按时间倒序展示（时间、图片、文字）；
删除：单条删除，应用内确认弹窗。

3.3 检测填报
检测人员现场手动填写幕墙缺陷检测结果，并可选择绑定到项目。

3.3.1 填报流程
进入检测填报
  → 拍照 / 从相册选择隐患图片（必填）
  → 手动填写：缺陷类型、工程部位、隐患等级、整改方案、相关规范（选填）、补充建议（选填）
  → 选择绑定项目（选填）
  → 提交（校验必填项）
      ├─ 失败 → 提示缺项
      └─ 成功 → 报告存入本地，进入「报告管理」列表；若绑定项目，报告与项目建立关联

3.3.2 填报字段
隐患图片 — 必填 — 形式：拍照/相册 — 要求：≤20MB；保存原图（本地 base64）；导出时嵌入 Word 附页
缺陷类型 — 必填 — 形式：下拉 + 自定义 — 要求：预置选项见 3.3.3，支持输入列表外的自定义值
工程部位 — 必填 — 形式：文本 — 要求：如"东立面三层 1# 立柱"
隐患等级 — 必填 — 形式：三选一按钮 — 要求：高 / 中 / 低（默认中，可改）
整改方案 — 必填 — 形式：多行文本 — 要求：整改措施
相关规范 — 选填 — 形式：多行文本 — 要求：违反的标准条款（标准名称 + 条款号），每行一条
补充建议 — 选填 — 形式：多行文本 — 要求：人工补充说明
绑定项目 — 选填 — 形式：下拉 — 要求：选项来自项目管理列表，显示"项目编号 - 房屋名称"；默认"不绑定"
报告人 / 部门 — 自动 — 形式：— 要求：取当前登录用户，不可改

3.3.3 预置缺陷类型（下拉选项）
a) 玻璃面板碎裂缺失
b) 密封胶开裂
c) 幕墙面板缺陷（玻璃）
d) 幕墙面板缺陷（石材）
e) 幕墙面板缺陷（铝板）
f) 半隐框外表面损伤
g) 明框外框外表面损伤
h) 广告立牌缺陷
i) 红外热成像异常
j) 其他（自定义输入）

3.4 报告管理
a) 列表按提交时间倒序：缺陷类型、隐患等级徽标、工程部位、图片缩略图、时间；
b) 顶部统计：总数及高/中/低数量；
c) 按隐患等级（高/中/低）筛选；
d) 点击查看报告详情（全字段 + 大图）；
e) 删除报告：应用内确认弹窗；如已绑定项目，删除后自动解除与该项目的关联；
f) （可选）单份报告导出为文本 / JSON 文件。

3.5 项目管理

3.5.1 项目信息
项目编号 — 必填 — 说明：唯一性建议校验
房屋名称 — 必填
房屋地点 — 选填
委托单位 — 选填
检测日期 — 选填 — 说明：日期选择

支持新建、编辑、删除（删除需应用内确认弹窗）。项目列表显示：编号、名称、记录数，支持查看/编辑/删除快捷操作。

3.5.2 检测记录
项目详情内添加"检测记录"，提供两种模板（选择模板后进入表单）：
a) 模板 A：幕墙立柱截面尺寸检测结果记录
b) 模板 B：幕墙横梁截面尺寸检测结果记录

两模板字段结构一致，仅名称与"截面尺寸要求"下拉选项不同：
楼层 — 必填 — 说明：如"六层"
构件位置 — 必填 — 说明：如"1"
尺寸结果 (mm) — 选填 — 说明：如"12+75"
截面尺寸要求 — 选填 — 说明：下拉预置（模板 A 与 B 各自的规范条文）
厚度检测 — 说明：1~6 个检测面（A/B/C/D/E/F），每面 5 个厚度值，最小值自动计算并展示

截面尺寸要求预置选项示例：
a) 立柱（模板 A）：
  - 立柱铝型材开口部位的厚度不应小于 3.0mm，闭口部位的厚度不应小于 2.5mm
  - 立柱铝型材开口部位的厚度不应小于 5.0mm，闭口部位的厚度不应小于 3mm
b) 横梁（模板 B）：
  - 当横梁跨度不大于 1.2m 时，铝型材截面主要受力部位的厚度不应小于 2.0mm
  - 当横梁跨度大于 1.2m 时，其截面主要受力部位的厚度不应小于 2.5mm

同一项目可混合保存两类模板的记录；记录支持新增、编辑（编辑时模板类型不可切换）、删除、逐条展开查看厚度明细表。

3.5.3 项目与报告的关联
a) 检测填报时选择了该项目（3.3.2"绑定项目"），即建立关联；
b) 一个项目可关联多份报告；一份报告只关联一个项目；
c) 项目详情页提供"导出 Word"，可将关联报告作为附页输出（见第四章）。

3.6 统计
a) 报告总数、高/中/低等级分布；
b) 最近 7 天活动（每日速记数、报告数，柱状/图表展示）；
c) 缺陷类型 Top 5；
d) 速记总数。

3.7 我的
a) 用户信息卡：姓名、部门、部门编码、工号（有则显示）；
b) 数据概览：速记数、报告数；
c) 数据管理：清除全部速记、清除全部报告（均需应用内确认弹窗，提示不可恢复）；
d) 退出登录；
e) 应用信息（名称、版本、出品部门）。

四、Word 检测报告导出

项目详情页点击「导出 Word」，生成 .docx 文件并触发下载。

4.1 导出交互
a) 项目无关联报告：直接导出；
b) 项目有关联报告：二选一是否关联报告：
  - 「附加 N 份并导出」——正文后追加检测报告附页；
  - 「仅导出检测报告」——不含附页；
c) 文件命名：`项目编号_房屋名称_检测报告.docx`。

4.2 文档结构
a) 章节标题 + 项目基本信息段（项目编号/房屋名称/房屋地点/委托单位/检测日期）
b) 立柱检测结果章节（仅当存在立柱记录）
c) 横梁检测结果章节（仅当存在横梁记录）
d) 备注段（固定文案：备注：检测构件位置详见检测工作内容附件 18。）
e) 检测报告附页（每份关联报告独立成页，仅导出含附页时）

4.3 立柱 / 横梁检测表格式（两表结构相同）

原始数据表参考（横梁示例）：
楼层 | 检测构件位置 | 尺寸检测结果(mm×mm) | 检测面 | 厚度检测结果(mm) | 最小值 | 横梁截面尺寸截面要求(mm)
     |              |                    |        | 1°  2°  3°  4°  5°  |        |
六层 | 6°           | 82×76              | t°     | 2.14 2.12 2.11 2.10 2.10 | 2.10 | 当横梁跨度不大于1.2m时...
六层 | 7°           | 82×76              | t°     | 2.15 2.12 2.18 2.19 2.15 | 2.12 | (同上)
六层 | 8°           | 82×76              | t°     | 2.14 2.15 2.16 2.14 2.15 | 2.14 | (同上)
二十三层 | 9°        | 82×76              | t°     | 2.14 2.14 2.14 2.15 2.14 | 2.14 | (同上)
二十三层 | 10°       | 82×76              | t°     | 2.17 2.16 2.15 2.13 2.10 | 2.10 | (同上)

数据行规则：
- 厚度值保留两位小数；"最小"列显示该面 5 次检测的最小值；
- 截面尺寸要求为空时显示"无"。

排版要求：
- 所有单元格内容水平居中 + 垂直居中（合并单元格内容在整个合并区域居中）；
- 表格整体页面居中，固定列宽布局，总宽约 A4 版心（≈8800 twips）；
- 列宽按内容自适应：取每列表头文字与数据内容的最大宽度权重（中文按 2、数字字母按 1）按比例分配，数值列窄（约 480~560 twips）、要求列宽（上限约 2600 twips，超长自动换行）；
- 行高：表头行最小 600 twips、数据行最小 400 twips（"至少"规则，内容多时自动撑高）；
- 单元格内边距：上下 60、左右 80 twips。

4.4 检测报告附页格式
每份关联报告独立成页（前加分页符）：
1. 标题（居中、加粗、16pt）：`检测报告附页（N/总数）`；
2. 信息表（两列，标签列加粗居中约 1600 twips，内容列左对齐）：

标签：缺陷类型 — 内容来源：报告的缺陷类型
标签：工程部位 — 内容来源：—
标签：隐患等级 — 内容来源：高/中/低
标签：整改方案 — 内容来源：多行文本
标签：补充建议 — 内容来源：空则显示"无"
标签：相关规范 — 内容来源：多行（按行拆分显示），空则"无"
标签：报告人 — 内容来源：姓名（部门）
标签：报告时间 — 内容来源：yyyy-MM-dd HH:mm
